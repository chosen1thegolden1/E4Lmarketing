# Handoff bundle

`E4L-site-handoff.zip` is the everything-in-one package for whoever deploys
the site into GoHighLevel: the start-here sheet, the full deploy guide, the
eight built pages, every image, the source, and Malik's agent notes.

It is a snapshot. The source of truth is the rest of `site/` and `assets/`.
Rebuild the zip after any change that matters to the deployer.
