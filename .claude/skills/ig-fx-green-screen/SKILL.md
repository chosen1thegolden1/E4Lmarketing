# Green screen (15)
Follow the house rules in `ig-story-editor` (canvas, fonts, colors, captions, render pipeline) unless the brief overrides them.

**Look**
- Backdrop: violet `#5B3DF5` filling the frame.
- A UI screenshot or screen recording card (light theme, r=20) fills the top 60 % (e.g. a timer
  "24:59", "Edit today's reel" task rows).
- A serif headline (Instrument Serif, 90 px, ink) across the middle: "✳ Editing … itself."
  The subject cut-out (waist-up, bottom-center) covers part of it, so the text sits *behind* the head.
- Captions still render on top.

**Timing**: cut in hard on the beat. The UI can scroll or tick during the hold.

**Build**: backdrop, then UI card, then serif text, then subject matte (from any background; a real green screen is not required).
