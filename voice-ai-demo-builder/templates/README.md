# Templates

Drop-ins that the renderer fills per prospect:

- `demo-page.html` — the existing E4L demo page (gold `#FFC200` on black, Rethink Sans,
  gold logo top-left, ROI strip, "tap to talk" hero). **Paste it here** — the renderer
  will template the copy slots and inject the GHL Voice AI Chat Widget embed.
- `fonts/` — Fineday display font files for self-hosted `@font-face`. **Add the font
  files here** (woff2 preferred). Rethink Sans loads from Google Fonts.

Nothing in here is generated — these are the masters.
