# Daily Notes

Auto-generated by the Command Center. Each day gets one file: `YYYY-MM-DD.md`.

- **`/brief`** writes the Morning Brief here each morning.
- **`/wrap`** appends the end-of-day Wrap-Up (done, open loops, carry-overs) to
  the same file.

These are your running record — safe to read back anytime to see what a given
day looked like.
