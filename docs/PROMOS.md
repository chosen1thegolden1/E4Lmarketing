# Promo decisions — Chosen's word only

A seasonal email can only carry a deadline if something really ends. The calendar ends by
itself. **A sale ends only if it is written here.**

This file exists so no session ever borrows Black Friday's urgency for an offer that
doesn't exist. The Tuesday writer reads it. If the target week has a commercial holiday in
it and there is no live row here, the batch gets written **without** a promo and the writer
asks Chosen rather than inventing one.

## What a promo needs before it goes in a row

From `jfsi.md`: a **reason why** it exists and why it ends, **one offer** (not a menu), and
a **real deadline** that gets kept. Plus which list it's for, since the agency front end is
the Game Plan Call and the student front end is the book.
