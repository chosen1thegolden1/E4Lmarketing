# Style guide — E4L AI Audit reel

Source: E4L brand (README brand guidelines, revenue-leak-scorecard, GEO report). No external reference video;
the grammar is "product-film UI motion": one container that never cuts.

- **Palette:** canvas `#0B0B0A` (warm black) · surface `#F7F5EF` (report paper) · ink `#111111` · dim `#8F897C`
  · **one accent: gold `#FFC200`**.
- **Type:** display = Rethink Sans 800, tracking -3%, left-aligned, never centered on a gradient.
  UI / kicker = Space Mono 700, uppercase, tracking +12% (the report's own brand line).
- **Container:** one rounded rectangle lives the whole film: gold block → search pill → answer card → report
  → receipt card → full-frame gold → CTA button. Size, radius and fill are `track()` springs.
- **Shot length:** 2 s per state (one bar at 120 BPM). Morphs start ~80 ms before the downbeat so they land on it.
- **Text in/out:** type rises out of a mask line (spring, no overshoot). Container content swaps behind a short blur.
  Nothing fades in from nothing.
- **Cursor:** drives every UI change (send, row scan, column scan, receipt pick, CTA press).
- **Camera:** push into the report's platform columns (8–10 s), pull back out for the receipts.
- **Texture:** none. Flat, crisp, real screenshots.
