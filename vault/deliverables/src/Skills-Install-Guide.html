Your Skills folder has two folders. Upload to Claude or ChatGPT holds the six zip files. No Skills on your plan - Project version holds the same six skills as copy-paste instructions.

Option A: Install in Claude

1

Don't unzip the file

Pick a zip from Upload to Claude or ChatGPT. Claude wants the zip as it is.

2

Open Settings, find Skills

In Claude, open Settings and look for Skills (under Capabilities). Turn Skills on if it's off.

3

Upload the zip

Repeat for each skill you want. Six uploads takes about five minutes.

4

Start a new chat and ask

Ask for what you need in plain words, like write me 3 ads for my fall special. Claude picks up the right skill on its own.

Menu names in Claude move around. If you can't find Skills, or your plan doesn't have it, use Option C. It does the same job.

Option B: Install in ChatGPT

If your ChatGPT plan has Skills, upload the same zip files there, the same way. If it doesn't have Skills yet, use Option C.

Option C: Project version (any plan, ChatGPT or Claude)

1

Create a new Project

In ChatGPT or Claude, create a Project. In ChatGPT a custom GPT works too.

2

Add the skill's prompts file

Open No Skills on your plan - Project version, then the skill's folder. Upload prompts.md to the Project's files (or the GPT's Knowledge). Clip Finder doesn't need one.

3

Paste the instructions

Open Project instructions.txt, copy everything below the line, and paste it into the Project's instructions. Save.

4

Chat inside that Project

Every new chat in that Project runs the skill.

Save your Business Card

The first time you use any skill, it asks six quick questions and gives you a Business Card. Save it in your notes. Paste it into any new chat, or add it to your Project files, and every skill skips the setup.
